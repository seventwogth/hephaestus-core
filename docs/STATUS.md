# Статус реализации относительно IDEA.md

## Уже сделано

- Зафиксирован MVP-стек генерируемых приложений: React, TypeScript, Vite, Go, chi, PostgreSQL, REST и Docker Compose.
- Создан базовый монорепозиторий ядра Hephaestus.
- Добавлены контракты артефактов `SPEC`, `PLAN`, `TASKS` и `STATUS`.
- Добавлен шаблон генерируемого приложения с frontend, backend, Docker Compose и тестами.
- Добавлен механизм создания проекта из шаблона.
- Добавлен sandbox для безопасных файловых операций и запуска allowlist-команд.
- Добавлен adapter-контракт для запуска агентных ролей через модельный провайдер.
- Добавлен CLI для создания проекта из JSON-спецификации.
- Добавлен валидатор проекта, который выполняет проверки и пишет `REVIEW.md`.
- Документация и пользовательские тексты шаблона переведены на русский.

## Частично сделано

- Оркестратор умеет создавать проект, сохранять начальные артефакты и запускать один агентный этап через `ModelProvider`.
- Проверочный этап уже существует как отдельный пакет и CLI-команда, но еще не встроен в полный конечный автомат генерации.
- `REVIEW.md` формируется валидатором, но агент-исправитель пока не использует его для циклов исправления.

## Следующие крупные шаги

1. Встроить валидатор в конечный автомат оркестратора: `GENERATING -> TESTING -> READY/FAILED`.
2. Добавить агент аналитики требований, который превращает текст пользователя в `ProjectSpec`.
3. Добавить агент-архитектор, который формирует `PLAN.json` и REST API-контракт.
4. Добавить генерацию backend-модулей Go поверх шаблона.
5. Добавить генерацию frontend-страниц и API-клиента поверх шаблона.
6. Реализовать ограниченный цикл исправлений по `REVIEW.md`.
7. Подключить Telegram-бота как пользовательский интерфейс MVP.

## Важные расхождения

- В `IDEA.md` первоначально упоминается Node.js backend, но для генерируемых приложений принят backend на Go по текущему продуктовому решению.
- Prisma из первоначального варианта стека не используется вместе с Go backend. Для будущего backend-слоя нужно выбрать подход к миграциям и SQL-доступу: `sqlc`, `goose`, `tern` или другой фиксированный вариант.
- Автохостинг остается вне MVP, как и описано в `IDEA.md`.
